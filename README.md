## 🚀 Featured Project

### 🍽️ RezeptRoulette

A full-stack web application that helps users discover recipes, decide what to cook, plan meals for the week, and automatically organize their shopping.

**Key features:**

- 🎲 Random recipe selection
- 🔍 Recipe discovery and filtering
- 📅 Weekly meal planner
- 🛒 Automatic shopping lists
- ♻️ Food Rescue based on available ingredients
- ❤️ Favorites and recipe ratings
- 🌙 Light & dark mode

**Tech Stack**

`Python` `FastAPI` `JavaScript` `HTML5` `CSS3` `SQLite` `REST API`

🔗 [Live Demo](https://rezeptroulette-1.onrender.com/)
